# Dipesh & Kirti — Wedding Website

Static wedding invitation site for Dipesh & Kirti, 3–4 January 2027, Krishna Hotel & Resort, Pushkar.

- `index.html` — the whole site (no build step). Wedding details (functions, WhatsApp number, countdown time) live in the `WEDDING` object at the top of the script.
- `img/` — couple photos.

Deploy: import this repository on Vercel (framework preset "Other", no build command), or enable GitHub Pages from the `main` branch root.
